# Расширение Personal Activity Time

Локальная интеграция с браузером: расширение передаёт активную вкладку
(URL + заголовок) в трекер через native messaging. **Данные не покидают
компьютер** — соединение идёт только с `Pat.NativeHost.exe` на этой машине,
который пишет в ту же локальную SQLite-базу.

Подходит для Chrome, Edge и других Chromium-браузеров (Firefox использует
другой протокол — пока не поддерживается).

## Установка (5 минут, без админ-прав)

1. Собрать приложение: `dotnet build` в корне репозитория.
2. Открыть в браузере `chrome://extensions` (в Edge — `edge://extensions`),
   включить **Режим разработчика**.
3. **Загрузить распакованное расширение** → выбрать папку `extension/`.
4. Скопировать **ID расширения** (32 буквы) на карточке расширения.
5. В трекере: Настройки → «Интеграция с браузером» → вставить ID →
   **Установить**. Это запишет манифест хоста и ключи реестра HKCU
   для Chrome и Edge.
6. Полностью перезапустить браузер.

После этого во вкладке «Сегодня» появится карточка «Браузер» с доменами
и визитами.

## Как это работает

- `background.js` (MV3 service worker) ловит `tabs.onActivated`,
  `tabs.onUpdated`, `windows.onFocusChanged` и шлёт активную вкладку
  через `chrome.runtime.connectNative`.
- `Pat.NativeHost.exe` читает сообщения из stdin (4 байта длины + JSON),
  извлекает домен, дедуплицирует и пишет событие `BrowserVisit` в базу.
- Не-web схемы (`chrome://`, `file://`, `about:`) не записываются.
- Пока трекинг на паузе (файл-маркер `tracking.paused`), хост ничего не пишет.
- Хост не имеет сетевого доступа и не отвечает в stdout.
